Dieser Bereich beschreibt die technische Umsetzung von `EtherFood`, ohne
Kanon oder Gamedesign neu auszulegen.

Architekturseiten halten dauerhafte technische Strukturen fest. Features
dokumentieren vorhandenes Verhalten. Technische Entscheidungen begründen
größere Architekturänderungen. Komplexe Arbeiten verwenden fortlaufend
gepflegte Pläne nach [`.agent/PLANS.md`](../../../.agent/PLANS.md).

Die verbindlichen Spielvorgaben stehen unter
[Kanon](../../game/canon/index.md) und
[Gamedesign](../../game/design/index.md). Die unveränderte englische
[Forge2D-Grundlage](../.forge2d-template/index.md) dokumentiert die geerbte
technische Basis.
