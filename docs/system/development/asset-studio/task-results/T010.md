aufklappbaren Gruppen, Kontextaktionen für Akte/Kapitel/Nebenkarten, Zoom,
Pan, Auswahl/Fokus, Breadcrumb und zusätzlichem Baum. Layout speichert
Position/Größe/Collapse getrennt von fachlichen Revisionen. Verwendungen
zeigen im Baum Herkunft und verweisen auf dieselbe Asset-ID. Details werden
erst bei Auswahl geladen; keine Vorschau-Bilddateien beim Projektstart.
