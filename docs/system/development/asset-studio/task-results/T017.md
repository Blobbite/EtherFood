## Verträge und Entscheidungen

**studio-job-v1** ist ausdrücklich eine technische Ausführungshülle, nicht
der bereits vorbereitete Bildvertrag aus T002. Diagnose und Help produzieren
keine Grafik-/Künstlerfreigaben. Der sichere Betrieb ist zunächst auf Linux
mit `/proc` beschränkt. Kein neues Paket, keine Systeminstallation. Windows
wird vor Start ehrlich abgewiesen. Die Entscheidung verhindert einen nur
scheinbar vollständigen Abbruch ohne beherrschte Kindprozesse.

Die installierte QProcess-Schnittstelle und die offiziellen Referenzen zu
[Qt-Prozessen](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QProcess.html) sowie
[Python-Subprozessen](https://docs.python.org/3.11/library/subprocess.html)
wurden geprüft. Kein blockierendes Qt-Warten im Hauptthread; derselbe
Supervisor bedient Core und GUI. Rohlogs und strukturierte Ereignisse getrennt.
