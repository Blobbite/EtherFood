# Pixel-Art-Bildsatz für das Portal-Labor

Dieser Ordner enthält die sechs vom Benutzer bereitgestellten PNG-Vergleichsbilder.
`F5 → Darstellung → Pixel Art` verwendet sie für Boden, Portale, Lampen,
Objekte, Monsterplatzhalter und Partikel in allen Portal-Labor-Räumen.

Die Originaldateien bleiben unverändert. Godot importiert sie verlustfrei
ohne Größenlimit und ohne Mipmaps. Ihre verschiedenen Bildauflösungen werden
bei der Darstellung auf die gemeinsamen Weltgrößen angepasst.

Die aktuellen PNGs sind RGB-Bilder ohne Alphakanal. Schwarze Hintergründe
sind deshalb auch im Spiel sichtbar, besonders bei Monstern und Partikeln.
Freistehende Objekte können später durch gleichnamige PNGs mit transparentem
Hintergrund ersetzt und erneut importiert werden; die Zuordnung bleibt bestehen.

Dateinamen, Größen und Ersatzverhalten sind in [der Ordnerübersicht](../README.md)
beschrieben. Die Herkunft als Testdatei stellt keine finale Grafikfreigabe dar.
